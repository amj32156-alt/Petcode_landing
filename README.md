# 펫코드 광고 웹앱

반려동물 유전자 분석 기반 맞춤형 펫푸드 구독 서비스 펫코드의 광고 웹앱 프로젝트입니다.
깃을 통한 지속적인 버전 관리와 기능 확장을 중심으로 운영합니다.

---

## 프로젝트 개요

Petcode는 반려동물의 유전자에 담긴 신호를 읽어 건강·체질·선천적/후천적 질병 리스크를  해석하고 그에 맞는 사료·간식·케어를 제안하는 서비스입니다.

검사 키트로 시작된 데이터는 추천에서 구매, 그리고 구독까지 자연스럽게 이어지며 하나의 흐름을 만들어 경험에 의존하던 선택을 데이터 기반 의사결정으로 전환합니다.

'반려동물에게 가장 적합한 맞춤형 케어'를 지속적으로 제공하는 것이 펫코드의 핵심 가치입니다.

## 깃 커밋 관리 규칙

| 말머리 | 의미 | 사용 예시 |
|-------|------|----------|
| chore | 초기 세팅 및 환경 설정 | chore: 프로젝트 초기 세팅 |
| feat | 새로운 기능 추가 | feat: 뉴스레터 구독 기능 추가 |
| style | UI 및 스타일 수정 | style: 메인 배너 디자인 수정 |
| fix | 오류 수정 | fix: 파비콘 경로 오류 수정 |
| refactor | 코드 구조 개선 | refactor: 섹션 구조 정리 |
| docs | 문서 수정 | docs: README 업데이트 |
